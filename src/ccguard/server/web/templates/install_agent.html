Установка агента ccguard

Агент — это endpoint-часть ccguard, которая сканит конфигурацию Claude Code на машине разработчика, отправляет inventory на сервер и применяет политику (PreToolUse hook). После установки агент зарегистрируется при первом ccguard sync и появится на странице Машины.

1

Получи agent-токен

На странице Настройки → Токены агентов создай новый токен с понятным label (например, имя машины: laptop-tim). Токен показывается один раз — скопируй сразу в безопасное место.

2a

Локальный запуск (для разработки)

Если репозиторий уже склонен на эту же машину:

# из корня репо
pip install -e .

# зарегистрировать PreToolUse hook в settings.json Claude Code
ccguard install --scope user

# отредактировать конфиг: вписать server.url и token
$EDITOR ~/.ccguard/config.yaml
# server:
#   url: http://localhost:8000
#   token: ccg_xxxxxxxxxxxx     # из шага 1

# первый sync — зарегистрирует машину
ccguard sync
2b

На удалённую dev-машину

Скопируй snippet ниже, подставь свои SERVER_URL и TOKEN, выполни на целевой машине под пользователем разработчика (не под root — агент живёт в ~/.ccguard). 

export SERVER_URL="https://ccguard.example.com"
export TOKEN="ccg_xxxxxxxxxxxx"

# TODO: replace with public release URL once published.
# Пока репо приватный — используй git+ssh или скопируй колесо вручную.
pip install --user git+https://github.com/timderbak/ccguard.git

# хук в Claude Code (для текущего юзера)
ccguard install --scope user

# конфиг
mkdir -p ~/.ccguard
cat > ~/.ccguard/config.yaml <<EOF
server:
  url: $SERVER_URL
  token: $TOKEN
EOF

# фоновый daemon (launchd на macOS / systemd --user на Linux)
ccguard-daemon install
ccguard-daemon start

# проверить
ccguard sync

После первого успешного sync машина появится во вкладке Машины. Daemon будет синкаться каждые ~5 минут.

3

Проверь, что всё подключено

  • На странице Машины появилась запись с label из конфига.
  • В разделе Аудит начали приходить события (если разработчик уже работает с Claude Code).
  • На Скан скиллов появились результаты LLM-сканера (если он включён в Настройках).

Для разработки

Чтобы посмотреть, как UI выглядит «с данными», не подключая реальный агент, запусти opt-in seed: 

ccguard seed-demo --help

Создаёт demo-машину и серию синтетических событий. Только для локальной разработки.
