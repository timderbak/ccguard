# UI редизайн — Фаза 1 (план реализации)

> **For agentic workers:** реализовать по задачам, TDD, коммиты в master, регресс зелёный. Детали дизайна — в `docs/superpowers/specs/2026-06-08-ui-redesign-design.md`.

**Goal:** вывести наружу витрину (Карта покрытия ТЗ-08) и сделать понятный Дашборд в тёмном «Fortexa»-скине, не трогая детект-движки/enforce/БД (только read-only роуты).

**Architecture:** FastAPI + Jinja2 + HTMX (стек не меняем). Новые роуты в `web/routes.py` читают существующие сервисы. Тема — переменные/классы в `base.html`. Каждый экран — со своим integration-тестом по образцу `tests/integration/test_web_smoke.py`.

**Tech Stack:** FastAPI, Jinja2, HTMX, Tailwind(CDN), Plus Jakarta Sans.

Порядок (от низкого риска к высокому):

### Task 1 — Карта покрытия `/coverage` (net-new, витрина ТЗ-08)
**Files:** Create `templates/coverage_map.html`; Modify `web/routes.py` (+route `coverage_page`), `base.html` (+nav-ссылка); Test `tests/integration/test_coverage_page.py`.
- Роут читает `coverage_service`: `techniques_covered/uncovered`, `coverage_by_tactic`, `coverage_by_control_type`; на технику — `coverage_detail`.
- Шаблон: точечная сетка тактик×покрытие, разбивка PREV/DETECT/SCOPE, список дыр (только in_scope), вне-скоупа — приглушённо. Тёмные Fortexa-карточки (self-contained).
- Тест: логин → GET /coverage → 200 + наличие тактик/«покрытие»/control-type.
- Commit.

### Task 2 — Тёмная тема «Fortexa» + сайдбар ② в `base.html`
**Files:** Modify `base.html` (тема, шрифт Plus Jakarta Sans, ② группы Постура/Детект/Управление, все текущие ссылки сохранить + добавить Карта покрытия/Атаки/Индикаторы/Корреляции/Фиды).
- Сохранить классы `cc-nav-link/cc-nav-group/cc-surface/cc-eyebrow/cc-sev*/cc-display/cc-mono` (рестайл тёмными), блоки `title/content/content_anonymous`, hrefs+подписи (для тестов nav).
- Прогнать UI-тесты, починить задетое (copy/обновить ассерты при необходимости).
- Commit.

### Task 3 — `surface_score_service` (новый, read-only)
**Files:** Create `services/surface_score_service.py`; Test `tests/unit/test_surface_score.py`.
- `compute_surface_score(session) -> dict` (score 0–100 + breakdown: #MCP, #риск). Стартовая формула из спеки §7.
- Commit.

### Task 4 — Дашборд `/` рестайл (Fortexa)
**Files:** Modify `overview.html` (или новый `dashboard.html`) + `routes.py` (контекст: surface_score, kpi, лента).
- KPI-стрип (детекты/блок/угрозы/фиды) + сегментный gauge (surface_score) + таблица инвентаря + лента активности.
- Сохранить данные, которые проверяют существующие overview-тесты (имя машины, статус).
- Обновить/добавить тесты. Commit.
